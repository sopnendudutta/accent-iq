# AccentIQ Design System Direction

## Product feeling

AccentIQ should feel like a calm, premium AI pronunciation coach.

It should not feel like:
- a random student project
- a generic dashboard template
- a noisy AI tool
- a childish language-learning game
- a dark crypto/SaaS interface

It should feel:
- warm
- focused
- human
- trustworthy
- educational
- modern
- premium but simple

## Design inspiration

Use DESIGN.md as broad inspiration only.

AccentIQ should borrow:
- warm editorial calmness
- soft off-white surfaces
- generous spacing
- readable typography
- focused cards
- minimal visual noise
- human assistant-like tone

Do not directly copy another brand.

## Core UI priorities

### Home page

The home page should quickly answer:

1. What is AccentIQ?
2. Who is it for?
3. What should the user do next?

It should have:
- one clear hero message
- one primary CTA
- one secondary CTA
- simple explanation of text and voice-to-text pronunciation practice
- no clutter

### Pronunciation page

This is the main product page.

The user should clearly see:
1. input area
2. accent selection
3. analyze action
4. clean result card

The result should show only:
- phonetic spelling
- syllables
- mouth / tongue / lip guidance
- practice tips
- example sentence

Hide or visually reduce:
- IPA
- stress pattern
- common mistakes
- slow practice
- repeat count
- technical labels

### Result card

The result card should feel like a teacher explaining clearly.

It should:
- be spacious
- use clear section titles
- make phonetic spelling visually prominent
- make tips easy to scan
- avoid overwhelming the learner

### History and favorites

History and favorites should feel useful, not heavy.

They should:
- use clean cards
- show the word, accent, date, and key pronunciation
- avoid too much technical data
- support quick review

## Visual direction

Use:
- warm off-white background
- soft cream surfaces
- dark charcoal text
- warm terracotta/coral for primary actions
- muted tan or warm gray for secondary surfaces
- gentle borders
- soft shadows
- rounded but mature corners

Avoid:
- too many pills
- too many gradients
- harsh shadows
- tiny text
- crowded cards
- excessive borders
- too many competing buttons

## Typography

Use modern readable typography.

Headings should feel confident but not loud.

Body text should be comfortable to read.

Avoid:
- overly small labels
- too many uppercase labels
- dense paragraphs

## Spacing

Use more breathing room than before.

Pages should feel calm, not packed.

Cards should have enough padding.

Mobile spacing should feel native and comfortable.

## Buttons

Primary buttons should be obvious.

Secondary buttons should be calm.

Danger buttons should be rare and clear.

Avoid too many buttons competing in one section.

## Mobile design

Mobile should not feel like a squeezed desktop.

Mobile should:
- stack sections naturally
- keep input easy to use
- keep buttons full-width where useful
- keep result cards readable
- avoid cramped grids

## Future design rule

Before changing UI, ask:

1. Is this useful to the learner?
2. Is this visually calm?
3. Is this easy on mobile?
4. Does this make AccentIQ feel like a real product?
5. Is anything here just decoration?

If something does not help the user learn pronunciation, remove it or reduce it.
